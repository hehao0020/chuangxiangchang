# 创想场 · Chuangxiangchang

**面向 AI 时代的综合创作与体验社区：让每个人的想法成为可以被直接体验、评价和继续创作的作品。**

游戏、工具、互动故事、设计、学习模拟和其他创意可以共存在同一个平台。首页默认综合推荐；用户刷到感兴趣的作品，就能直接玩、使用或探索，也可以按分类查找。

> 当前状态：产品设计阶段。仓库包含产品需求文档与协作说明，尚无可运行的平台代码、在线演示或安装包。下列体验均为规划，未标为已完成的功能不代表已经实现。

## 为什么做这个项目

当越来越多人能借助 AI 把想法做成作品，作品需要一个适合发布、直接体验、反馈和持续更新的地方。

我们希望缩短“看到一个作品”到“亲自体验它”的距离，并让真实反馈帮助创作者改进作品。创作者可以使用任何 AI、可视化工具或传统开发方式，平台不以编程经验或模型品牌划分参与资格。

## 想做成什么样

同一个推荐首页里，可以出现：

| 作品 | 用户动作 |
| --- | --- |
| 一个 3D 射击游戏 | 开始游玩 |
| 一个配色或计算工具 | 立即使用 |
| 一个可旋转的房间设计 | 查看设计 |
| 一个可以选择走向的故事 | 进入故事 |
| 一个物理实验模拟器 | 调参探索 |

统一的是发现、发布、评论、收藏和关注；进入作品后，保留适合它的体验方式。分类帮助组织内容，首页无需先选分类。

推荐需要理解不同作品的价值：游戏可以看复玩，工具可以看任务完成和再次使用，不能用一套停留时长标准决定全部作品的质量。

## 第一版计划

首版先承接大家已经在其他工具里做出的作品，跑通：

**上传作品 → 审核与发布 → 首页推荐 → 直接体验 → 评论反馈 → 作者更新。**

- 综合推荐首页，可选分类筛选、搜索和关注流。
- 可扩展的作品分类，支持跨界作品和“其他”类别。
- 通用网页作品上传、独立分享地址和隔离体验。
- 评论、问题反馈、点赞、收藏和作者关注。
- 作者工作台、版本更新、基础数据和审核管理。

首版运行能力提案为自包含 HTML/网页 ZIP 包。多类作品从首版共存；外部联网、后端托管、账号支付、站内 AI 创作等能力分阶段评估。内容分类与技术能力分别管理。
